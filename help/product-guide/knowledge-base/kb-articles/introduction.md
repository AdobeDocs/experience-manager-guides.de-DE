# Experience Manager Guides-Wissensdatenbank

Die Wissensdatenbank enthält praktische, szenariogesteuerte Artikel für Experience Manager Guides, in denen gängige Konfigurationen, Anpassungen und Anwendungsfälle behandelt werden, die über die Kernproduktdokumentation hinausgehen.

| Kategorie | Beschreibung |
|---|---|
| Authoring | Tipps und Techniken zum Erstellen und Wiederverwenden von Inhalten im Editor, einschließlich Editor-Anpassungen, Metadatenverwaltung und Inhaltsvalidierung. |
| Handbücher zum Erweiterungs-Framework | Erfahren Sie, wie Sie die Experience Manager Guides-Benutzeroberfläche anpassen können. Dies reicht von den ersten Schritten mit dem Erweiterungs-Framework bis zum Erstellen benutzerdefinierter Komponenten, Widgets und Anpassungen von Review-Programmen. |
| Externe Daten - Source | Anleitung zur Integration und Konfiguration externer Datenquellen-Connectoren mit Experience Manager Guides. |
| Publishing | Best Practices für die Ausgabegenerierung, einschließlich nativer PDF, DITA-OT, AEM Sites-Vorlagen und Veröffentlichungskonfigurationen auf Basis von Microservices. |
| Workflows | Konfigurieren und verwenden Sie Workflows der Nachgenerierung, um Schritte nach der Erstellung der Ausgabe zu automatisieren. |
| Übersetzung | Anweisungen, wie Sie die Übersetzungsleistung verbessern und verwalten können, welche Inhalte in die Übersetzung eingeschlossen oder von ihr ausgeschlossen werden. |
| Anwendungsfälle | Erfahren Sie mehr über die realen Szenarien wie bedingte Inhalte, die Arbeit mit Schlüsseln und kontextuelle Inhaltsvariablen in der veröffentlichten Ausgabe. |
