# MCP - Erweitern des Zugriffs auf verwaltete technische Inhalte

Erfahren Sie, wie das Model Context Protocol (MCP) KI-gestützte Erlebnisse ermöglicht, sicher mit AEM Guides über Anfragen in natürlicher Sprache zu interagieren und gleichzeitig die bestehenden AEM-Zugriffssteuerungen und -berechtigungen zu beachten. In dieser Sitzung erläutern wir die MCP-Architektur, -Konfiguration, -Authentifizierung und -Sicherheitsmodell, zeigen die derzeit unterstützten Funktionen auf und untersuchen praktische Anwendungsfälle, aktuelle Grenzen und wichtige Überlegungen. Außerdem werden Überlegungen zur Bereitstellung von AEM as a Cloud Service- und On-Premise-/AMS-Umgebungen behandelt, es wird gezeigt, wie MCP-fähige Clients eine Verbindung zu AEM Guides herstellen können, und es wird erörtert, wo MCP zu den umfassenderen KI-Funktionen von Adobe passt.
