# Editor anpassen {#id181AI0003PN}

AEM Guides ist mit einem leistungsstarken Editor gebündelt, mit dem Ihre Autoren DITA-Dokumente erstellen und bearbeiten können. Sie können die Symbolleiste des Editors anpassen, um alle Funktionen hinzuzufügen oder zu entfernen, auf die Sie über die Symbolleiste zugreifen können. Außerdem können Sie das automatische Speichern von Dateien konfigurieren, IDs für Elemente generieren, während sie in Ihre Dokumente eingefügt werden, und vieles mehr.
